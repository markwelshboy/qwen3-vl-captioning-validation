# Semantic V3 KISS Reset

## Why reset

The previous V3 research path progressively asked the same VLM to observe, qualify, justify, counter-qualify, and reconstruct its own observations. That produced a predictable failure mode: once the model formed an initial interpretation, later schema fields encouraged it to elaborate a coherent story around that interpretation.

A clarification generated by the same model is not independent evidence.

The design reset follows two investigation principles:

1. **Questions should not guide answers.**
2. **K.I.S.S. — Keep It Simple.**

## New architecture

```text
IMAGE
  |
  v
ONE VLM CALL
  |
  v
sparse semantic packet
  +
Pose v0.16 governed geometry
  |
  v
deterministic Fusion
  |
  v
Compose
```

The operational rule is:

> **Ask once, minimally. Govern deterministically. Write once.**

## What the VLM does

The image-conditioned model gets one opportunity to report salient visible facts.

Its output is deliberately sparse. The schema contains storage bins, not a questionnaire:

- subject
- body
- interactions
- scene
- composition
- uncertainties

All semantic bins may be empty.

The packet does **not** ask for:

- confidence scores
- evidence lists
- counterevidence
- landmark audits
- connectivity proofs
- hypothesis/observation duplication
- repeated qualifications
- second-pass semantic reconstruction

The model is told to omit uncertain details rather than elaborate them.

## Why this is safer

Repeated questioning of one generative model can bootstrap a weak impression into an internally coherent hallucination:

```text
weak impression
  -> label
  -> requested qualification
  -> invented supporting detail
  -> requested evidence
  -> more invented detail
  -> apparently well-reasoned but false story
```

The sparse packet prevents most of that loop by simply not asking the follow-up questions.

## Independent physical authority

The frozen `sam3d-relational-pose-profile-0.16` remains the independent geometric evidence family.

Pose v0.16 is responsible for structured physical authority such as:

- public broad posture
- withheld reconstruction vs observed authority
- posture modifiers
- governed physical relations

The VLM packet and Pose are different evidence families. Multiple strings from the VLM are not independent votes.

## KISS Fusion v0.1

The first deterministic Fusion is intentionally conservative:

- governed public Pose is the only structured posture authority;
- withheld Pose reconstruction remains provenance only;
- only positively asserted governed physical relations enter canonical truth;
- sparse semantic packet strings pass through without another LLM interpretation pass;
- no Analyze or Gestalt model calls exist in this path;
- no semantic-recovery LLM call is performed.

This first version intentionally does not build a large text-rule engine around sparse VLM phrases. New deterministic governance should be added only when calibration images demonstrate a general failure mode.

## Research trail

The x3p3 Extract, Analyze-over-Extract, Gestalt-over-Extract, and Fusion 3.0.x work remain in the repository as a reproducible research trail. They are not deleted or silently changed by this reset.

Their useful lessons survive in the new design, especially:

- crop defines the truth envelope;
- missing evidence is not negative evidence;
- reconstruction is not observation;
- semantic outputs from one model are one evidence family, not multiple votes;
- independent geometry can govern claims it is actually qualified to evaluate.

## Calibration rule

Do not add a new question to the VLM merely because one image was wrong.

When a calibration image fails, first ask:

1. Was the wrong claim volunteered by the sparse VLM packet?
2. Can frozen Pose v0.16 independently govern it?
3. Can deterministic Fusion resolve it without asking the VLM another question?
4. Is the failure general enough to justify any new rule?

The burden of proof is on adding complexity, not removing it.
